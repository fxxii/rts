# Project learnings

Record surprising failures or non-obvious constraints:

- Date / stable ID / short title
- Trigger and observed evidence (file:line, revision or issue)
- Failure mechanism
- One executable prevention/check
- Scope or expiry

At 20 entries or 2,000 words, distill using [maintenance](maintenance-protocol.md).
Keep active guidance focused on what to do; retain detailed incident records separately.
